# Crypto Tracker (Frontend)

Frontend en Angular standalone (v18) que consume el backend FastAPI.

## Instalación

```bash
npm install
```

Si no tienes un proyecto Angular ya creado, primero corre:
```bash
npm install -g @angular/cli
ng new crypto-tracker-frontend --standalone --routing --style=scss
```
y luego copia estos archivos dentro de `src/app` reemplazando los existentes.

## Correr

```bash
ng serve
```

Abre http://localhost:4200 (el backend debe estar corriendo en http://localhost:8000).
